## 🚀 How to Run the Website

1. Download or clone the project repository.
2. Open Visual Studio Code.
3. Click **File → Open Folder**.
4. Select the portfolio project folder.
5. Open `index.html`.
6. Install the Live Server extension if necessary.
7. Right-click inside the HTML editor.
8. Select **Open with Live Server**.
9. The website will open automatically in your browser.

## 🌐 How to Publish Using GitHub Pages

1. Log in to your GitHub account.
2. Create a new repository.
3. Upload all website files and folders.
4. Open the repository settings.
5. Select **Pages**.
6. Under Build and Deployment, select **Deploy from a branch**.
7. Select the `main` branch and `/ (root)` folder.
8. Click **Save**.
9. Wait for GitHub Pages to publish your website.
10. Open the published website link.
